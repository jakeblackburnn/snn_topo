# snn topology

General idea: compare the topological signatures of brain activity to that of SNNs trained with RL on comparable tasks.

### open questions:

- which biological dataset to use (must be the biggest and the best fit to the SNN)
- how to use topology to make comparable analyses on both
- how to set up the SNN task implementation
- how to extract data from the SNN comparable to the biological data
